# viz/assets/ — 样式、脚本与生成数据

本目录为 `viz/` 图册的共享资源层，被 10 个页面通过相对路径引用。

| 文件 | 职责 | 可否手改 |
|:---|:---|:---|
| `style.css` | 全部样式：主题令牌、布局、组件、演示模式 | 可以 |
| `app.js` | 共享交互：分面筛选引擎、主题切换、演示模式、页面导航 | 可以 |
| `charts.js` | 图表组件：环形、堆叠、矩阵、气泡、条形 | 可以 |
| `data.js` | 全部页面数据（约 97 KB） | **不可**，见下 |

## `data.js` 是生成物

由 `viz/build/extract.py` 扫描仓库生成，文件首行已标注「请勿手改」。
它的每个数字都能在仓库源文件里找到出处，页面上显示的口径说明见
[`../README.md`](../README.md) 的「数据口径说明」章节。

要更新数据，重新运行提取脚本，不要直接编辑：

```bash
python viz/build/extract.py
```

## 边界

- 本目录只服务 `viz/` 的离线页面，不被仓库任何 `make` 目标或 CI 检查引用。
- 不在此处引入第三方库文件；页面保持零依赖、纯离线。
- 维护规则见 [`../AGENTS.md`](../AGENTS.md)。
